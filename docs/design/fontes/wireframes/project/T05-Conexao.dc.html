Endereços: base 0 (CODESYS, pymodbus) ou notação clássica (MB_CLIENT, muitos SCADAs: coil 0 = 1, input register 0 = 30001). Ver o mapa de I/O

Como conectar

  1. No CODESYS, adicione um Modbus TCP Client (“Master” antes da V3.5 SP22) e um Modbus TCP Server Device embaixo dele.
  2. No dispositivo, use o IP 192.168.10.20, a porta 15003 e o Unit ID 1.
  3. Crie os canais: coil 0, entradas discretas 0–5, holding registers 0–1 e 10, input registers 0–5 (base 0).
  4. Baixe e rode o programa. Nesta página, aceite o pedido de conexão do seu IP.
